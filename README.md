# S3 Forge

Website for **S3 Forge**, a Windows app for programming any ESP32 board in the Arduino core: code editor, one-click upload, firmware flasher, serial monitor, live plotter, 96 compile-tested examples and an AI coder.

The site is a single `index.html` with screenshots in `shots/`. To start taking orders, set `checkoutUrl` (and `price` if needed) in the `STORE` object near the bottom of `index.html`.
